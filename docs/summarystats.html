Chapter 5 Summary Statistics

5.1 Measures of Central Tendency

Mean, Median and Mode are commonly used. Don’t forget that not all can be used for all types of variables. For nominal variables (e.g., Gender), only mode is appropriate. For ordered categorical variables (ordinal variables), mode and median can be used. All three can be used for numeric variables.

mean(iris$Sepal.Length)
## [1] 5.843333

The mean of Sepal.Length is 5.8433333.

median(iris$Petal.Length)
## [1] 4.35

The median of Petal.Length is 4.35

There is no built-in function for determining the mode. However, one can write a function to do that job. Please see the function below called mymode. This has been taken from the solutions discussed in response to a question on Stack Overflow.

# Function to determine the mode. Can also identify multiple modes
mymode <- function(x) {
  ux <- unique(x)
tab <- tabulate(match(x, ux)); ux[tab == max(tab)]
}

# Function to give the frequency of occurrence of mode
modecount <- function(x) {
  ux <- unique(x)
max(tabulate(match(x, ux)))
}

Let us put those function to use to determine the mode of a numeric variable first.

mymode(iris$Petal.Length) # Gives the mode(s) of Petal.Length
## [1] 1.4 1.5
modecount(iris$Petal.Length) # Gives the frequency of occurrence of the mode
## [1] 13

And now, a factor variable.

mymode(iris$Species)
## [1] setosa     versicolor virginica 
## Levels: virginica versicolor setosa
modecount(iris$Species)
## [1] 50

Note that all three types of species are identified as modes because there are 50 observations of each type.

5.2 Other measures of central tendency

  • Trimmed Mean: Means can be affected by outliers (extreme values). Trimmed means can provide a more robust measure in such cases. If there is a good explanation for the presence of the outliers, avoid using this.

Regular mean:

mean(iris$Sepal.Length)
## [1] 5.843333

5% trimmed mean

mean(iris$Sepal.Length,trim = .05) # knocks off 5% of the observations on each end.
## [1] 5.820588

10% trimmed mean:

mean(iris$Sepal.Length, trim = .1) # knocks off 10% of the observation on each end.
## [1] 5.808333

5.3 Measures of Dispersion (variation)

5.3.1 Range

min(iris$Sepal.Length) # minimum
## [1] 4.3
max(iris$Sepal.Length) # maximum
## [1] 7.9
range(iris$Sepal.Length) # should give the min and max
## [1] 4.3 7.9

5.3.2 Interquartile range: Difference between 25th and 75th percentile (or quantile)

E.g., 5th percentile or 5th quantile of a variable is the smallest number below which 5% of the observations of that variable lie.

quantile(iris$Sepal.Length,probs = .05)
##  5% 
## 4.6

The median is the 50th percentile value.

median(iris$Sepal.Length)
## [1] 5.8
quantile(iris$Sepal.Length,probs=.5)
## 50% 
## 5.8

25th quantile

quantile(iris$Sepal.Length,probs=.25)
## 25% 
## 5.1

75th quantile

quantile(iris$Sepal.Length,probs=.75)
## 75% 
## 6.4

Therefore, IQR is the difference between the 75th quantile and 25th quantile.

IQR(iris$Sepal.Length)
## [1] 1.3

5.3.3 Variance and Standard Deviation

var(iris$Sepal.Length)
## [1] 0.6856935
sd(iris$Sepal.Length)
## [1] 0.8280661

Note that the standard deviation is the square root of variance.
