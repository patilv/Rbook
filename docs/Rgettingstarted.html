Chapter 2 Getting Started with R

The first order of business would involve installing R.

  1. Download R for your computer based on its operating system from https://cloud.r-project.org/ - Select base R. Mac users may have to download the version compatible with the version of the Mac OSX of your laptop.
  2. Now install the software. (If using Windows, use the 64 bit version if that option is provided.) Once R is installed, open it. A console should open. Once you verify this, you can close the console and get out of the program. There will be no need to open this in the future.
  3. Get an IDE. I prefer to use R-Studio desktop. This can be downloaded from R-Studio’s website. Don’t forget to download the version compatible with your operating system. Install the software and open it. Whenever you open R-Studio desktop, it provides access to the R-interface through one of its panels. This is the reason we don’t have to open the R-console separately. (See point #2 from above.)

2.2 Organizing projects

  1. It is a good idea to organize analysis projects into separate folders of their own. Any output of the analysis and the reports you generate would also end up being saved in that folder.

  2. Naming conventions for folders, files, and variables: Avoid having any special characters and or spaces for names of folders, files and variables. Variable names can have underscores between words, for example, University_Standing or UniversityStanding would be perfectly fine. Use names that can help you and any reader of the report make sense of what it is that you are studying. Graham Williams has a good style guide for how to code in R. It can be downloaded from onepager.togaware.com.

  3. After opening R-Studio, always check on the working directory and set it to the specific location within the folder intended for the project.

2.3 Installing Packages from CRAN

install.packages("pkgname")
install.packages(c("pkgname1","pkgname2")) # For two or more packages

2.4 Installing a package from GitHub

if (!require("devtools")) install.packages("devtools") # Checks if the devtools package is available and if not, installs it from CRAN
devtools::install_github("githubaccountname/packagerepository")

2.5 Installed packages should be loaded for them to offer their functions for use

library(pkgname)

2.6 Setting your working directory

This helps in organizing the inputs/outputs of a project.

  • The current working directory can be determined using getwd()
  • A new working directory can be set using setwd(path to directory)
  • R-Studio makes this much easier to do using their GUI using Session -> Set Working Directory option
  • Using Projects in R-Studio also makes the process of switching working directories between different projects easier.

2.7 Reading data from different sources

Load R file

load("filename.Rda")

Delimited files text files

dataname=read.csv("datafilename.csv")# use ?read.csv to see options

Excel Files

install.packages("readxl") # https://github.com/hadley/readxl
library(readxl)
read_excel("excelfilename.xls") # reads xlsx extensions also
read_excel("excelfilename.xlsx", sheet = "nameofsheet")
read_excel("excelfilename.xlsx", sheet = 3)# for third sheet, as an example
read_excel("my-spreadsheet.xls", na = "NA") # if NAs are represented by non-blank cells, specify them with na=

SPSS/SAS/Stata files

install.packages("haven") # https://github.com/hadley/haven
library(haven)
read_sas("path/to/file") # SAS file
read_por("path/to/file") # SPSS por files
read_sav("path/to/file") # SPSS sav files
read_dta("path/to/file")# Stata

Many others

?read.table
?readClipboard

2.8 Saving data

save(dataframename,file="filename.Rda") # To R data
write.csv(dataframename,file="myfilename.csv") # to csv...see also ?write.csv
write.table(dataframename,file="myfilename.tsv",sep="\t") # to tab-separated file...see also ?write.table
